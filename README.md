# Sayanox Chain

### Next-generation Layer-1 blockchain built from scratch in Go

Performance · Decentralization · Security · Clean modular architecture

[![Go](https://img.shields.io/badge/Go-1.21%2B-00ADD8?logo=go&logoColor=white)](https://go.dev/)
[![Status](https://img.shields.io/badge/Status-Active%20Development-orange)](#)
[![License](https://img.shields.io/badge/License-TBD-lightgrey)](#)

> Experimental L1 focused on speed, security, and developer experience.  
> **Not production-ready** — do not use for real-value assets yet.

---

## Vision

Build a secure, scalable, and developer-friendly blockchain ecosystem that can support decentralized applications and future Web3 infrastructure without unnecessary complexity.

---

## Planned / In-progress Features

| Area | Details |
|------|---------|
| **Consensus** | Proof of Stake |
| **Networking** | Peer-to-peer |
| **API** | JSON-RPC + WebSocket |
| **Wallet** | Native wallet system |
| **Validators** | Validator network |
| **Explorer** | Block explorer |
| **Smart Contracts** | Planned |
| **Cryptography** | Ed25519 + SHA-256 |

---

## Technology Stack

- **Language**: Go
- **Crypto**: Ed25519, SHA-256
- **Storage**: LevelDB (planned)
- **API**: JSON-RPC, WebSocket
